[உக்ரசேனன் கூடாரம்]

உக்ரசேனன் : வீரசிம்ஹா! திடீரென புறப்படவேண்டியிருக்கும்... நமது படைவீரரெல்லாம் தயார்தானே!

வீர : தயார் அரசே!

உக்ர : (ஓலையொன்றைக் கொடுத்து) புருஷோத்தமனுடைய அரண்மனையில் நுழைந்து, வசந்தசேனையின் மூலம் இதை அக்ஷயனிடம் சேர்ப்பிக்கவேண்டும்.

வ. சே. : உக்ரசேனர் வந்துவிட்டாராம் சாது வேடத்தில் வருகிறார்களாம், எல்லோரும்...

போ. அக்ஷ. : சாதுக்கள்... வேடம்...

வ. சே. : என்ன அக்ஷயா?

போ. அக்ஷ. : ஒன்றுமில்ல. சாது வேடத்தில்தானம்மா பல சாம்ராஜ்யங்கள் கவிழ்ந்திருக்கின்றன...

வ. சே. : ஓகோ! ஆமாம்... அவர்களை எப்படி அரண்மனைக்குள் அழைப்பது?

அக்ஷ : ஆலோசிக்கவேண்டியதுதான்...

வ. சே : ஆலோசனையென்ன, அரை நொடியில் ஏற்பாடு செய்கிறேன்.

[உக்ரசேனனின் சாது கூட்டம் மேள வாத்தியங்களுடன் பக்தி முழக்கங்களுடன் வரவேற்கப்படுகின்றது...... அரசனும், வசந்தியும் சாது கூட்டத்தை பக்தி சிரத்தையுடன் மரியாதையுடன் வரவேற்று உபசரிக்கிறார்கள்......]

அரசன் : வரவேண்டும்...... வரவேண்டும்...... பாக்யவானானேன்.

<!-- source: pdf=68 printed=67 status=verified -->

உக் : பகவானின் பேரருள் சித்திக்கட்டும்... புருஷோத்தம ராஜன்... நாடகமே உலகம், நாளை நடப்பதை யாரறிவார்!......

அர : உண்மை உண்மை!......

உக் : இதுதான் ராணியோ!......

அர : (தலையை அசைக்கிறான்)......

உக் : மகாலஷ்மி!... கலிகால நளாயினி... ராணி...... மனம்போல் வாழ்வாய்!... எண்ணங்கள் நிறைவேறும்......

வ. சே. : வசந்தா... சுவாமிக்கு நமஸ்காரம் செய்!

வசந் : ஒருமையுடன் உனதுதிரு மலரடி நினைக்கிற உத்தமர் தம் உறவு வேண்டும்... விகடா பாடத்தை மறந்து விட்டேண்டா...

வ. சே. : போதும்...போதும்.

உக்ர : வாழ்க! வாழ்க...... ஏ ராஜன்... நல்ல சமயத்தில் தான் நான் வந்திருக்கிறேன். உனக்கு ஒரு பெரிய ஆபத்து காத்திருக்கிறது........

அர : ஸ்வாமி!......

உக்ர : அந்த ஆபத்திலிருந்து தப்பவேண்டுமானால் நீயும் உன் ராணியும் இந்த கணம் முதல் நாளை காலை வரையில் பிரிந்திருக்கவேண்டும்.

அர : அப்படியா?

உக்ர : இல்லாவிட்டால் மரணம் சம்பவிக்கும்...

வச : மகாராஜாவை பிரிந்திருப்பதா?......

அர : நாளை காலை வரையில்தானே வசந்தி!...

உக் : உம் - பிரியுங்கள்...பிரியுங்கள்...

வசந் : ஞாபகம் வந்துவிட்டது உள்ளொன்று வைத்து புறமொன்று பேசுபவர் உறவு கலவாமை வேண்டும்.

வ. சே. : வசந்தா

வசந் : மறவு பெண்ணாசை மறக்கவேண்டும்.

அர : டேய்! சும்மாயிரு!

வசந் : மதி வேண்டும்...

வ. சே : வசந்தா!

[வசந்தி போகிறான்]...

உக்ர : எல்லாம் கடவுள் செயல்! ராஜன்!... இந்த உடலம் சிறிது இளைப்பாறவேண்டும்...

<!-- source: pdf=69 printed=68 status=verified -->

அர : இதோ ஏற்பாடு செய்கிறேன்......

[அரசன் போகிறான். சாது வேடத்திலிருக்கும் உக்ரசேனனுடைய படை வீரர்கள் அரண்மனை எங்கும் பரவி காவலாளிகளைக் கொன்று அவர்களுடைய இடத்தை ஆக்ரமித்துக்கொள்கிறார்கள்.]
