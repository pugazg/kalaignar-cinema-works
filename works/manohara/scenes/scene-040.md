[குகை]

கேசரிவர்மன் : பழிகாரி ஓலை தயாரித்துவிட்டாள், அவள் காரியத்தை வெற்றிகரமாக்க கடைசி ஓலை கொஞ்சம் ஏமாந்தால் அதுவே நமக்கு சாவோலை ஆகிவிடும்!

சத்யசீலர் : விஷயத்தைச் சொல் வர்மா!

கே. வ : வசந்தனுக்கு முடிசூட்ட முயன்றாள் வஞ்சகி! மன்னர் மறுத்தார். ஆகவே இந்த மாளிகையை வசப்படுத்தி மகனை அரசனாக்க மாற்றான் உக்ரசேனனுக்கு மடல் அனுப்பியிருக்கிறாள்.

மனோ : உக்ரசேனன்! இமயபுரி வேந்தன்!

ராஜப் : ஆம்! நம் சாம்ராஜ்யத்தில் நுழைய சமயம் பார்த்திருப்பவன்.

கே. வ : உக்ரசேனனிடமிருந்து பதில் கொண்டு வருபவன் இந்த வழியேதான் வந்தாகவேண்டும். வாருங்கள் பார்ப்போம்.

[அட்சயன் குதிரையில் வருகிறான். மனோகரன் அவனை நிறுத்தி]

மனோ : யார் நீ!

அட் : என்னையா கேட்கிறாய்? நான் நான்தான்!

வர்ம : எங்கே போய்க்கொண்டிருக்கிறாய்?

அட் : போகவேண்டிய இடத்திற்கு!

[மனோகரனும் ராஜப்பிரியனும் அட்சயனைத் தாக்கி அவனை ஒரு கல்தூணில் கட்டிப் போடுகிறார்கள். மனோகரன் அட்சயனிடமிருந்து ஒரு கடிதத்தை எடுக்கிறான்.]

“அன்புள்ள வசந்தசேனைக்கு!

அட்சயனை துணைக்கு வைத்துக்கொண்டு அரண்மனைக்குள் ஆகவேண்டியதைக் கவனி. படைகளும் நானும் புறப்படுகிறோம். புருஷோத்தமனை தொலைப்போம். புது வாழ்வு தொடங்குவோம்.

உக்ரசேனன்.”

ராஜப் : துரோகம்... விடக்கூடாது இதை!

மனோ : இப்போதே புறப்படுவோம்... அந்த வக்ரபுத்திக்காரியை கூண்டோடு அழிக்கவேண்டும்.

கே. வ. : அழித்துவிட்டால் உங்கள் வீரம் வெளிப்படும். அந்த வேசியின் வேஷம் வெளிப்படாது. இளவரசே! அரை நொடியில் சாகடிக்க அல்ல நான் இப்படியெல்லாம் இவ்வளவு காலம் ஏங்கித் திரிவது? என்னாலும் முடியும் எப்போதோ செய்திருப்பேன்.

மனோ : ஏன் செய்யவில்லை?

வர் : விவேகம் இளவரசே! விவேகம். அப்போது கொன்றிருந்தால் அந்த கள்ளிக்காக கண்ணை இழந்த அரசர் கண்ணீர் வடித்திருப்பார். அவள் சூழ்ச்சிகள் அம்பலமாயிருக்காது. சூதுக்களை உலகம் தெரிந்துகொண்டிருக்கமுடியாது. அவளை சாகடிப்பதில் இல்லை நம் சாமர்த்தியம். அவள் சதிகளை அம்பலப்படுத்துவதில்தான் இருக்கிறது.

மனோ : அதற்கு வழி......

வர் : முள்ளை முள் கொண்டு எடுப்பது போல சூழ்ச்சியையால்தான் வெல்லவேண்டும். சொல்லுகிறேன் வாருங்கள்,
