[அரசன் மாளிகை]

காவலன் : மகாராஜா...... பைத்தியத்திற்கு வைத்தியம் பார்ப்பதில் மகா கெட்டிக்காரனாம் ஒருவன்...

அர : அப்படியா!... வசந்தியிடம் அவனை அழைத்துப் போ!......

காவலன் : உத்திரவு!......

[வசந்தசேனை அந்தப்புரம் காவலன் அக்ஷயன் வேடத்தில் உள்ள மனோகரனைக் காட்டி]

<!-- source: pdf=66 printed=65 status=verified -->

காவலன் : அம்மா—இவரை மகாராஜா தங்களிடம் அனுப்பினார். பெரிய வைத்தியராம்...

வசந்தி : யார்?......

போலி அக்ஷயன் : நான் ஒரு வைத்தியன். என் பெயர்..... உக்ரசேனத் தூதன்... [புரிந்துகொண்டு]

வசந்தி : நீளமான பெயர்...

[மனோகரன் கடிதத்தை வசந்தியிடம் நீட்டுகிறான். வசந்தி கடிதத்தைப் படித்துவிட்டு]

உமது பெயர்?

போலி அக்ஷயன் : அக்ஷயன்!

வசந்தி : அரசனை சரியானபடி ஏமாற்றியிருக்கிறீர்.

போ. அக்ஷ : ஆமாம்—என்னை யாரென்று யாராலும் கண்டுபிடிக்க முடியாது...

வச : சரி... நீர், வைத்தியரைப் போலவே......... நடித்துக் கொண்டிரும்—மற்றவைகளை நான் கவனிக்கிறேன்.

போ. அக்ஷ. : நடிப்பதா பிரமாதம்!...ஓ!...

* * *

வசந்தன் : ஏய் வைத்தியா... மருந்து மருந்துண்ணு உயிரை வாங்குறே!

வைத் : அதுக்குத்தான் முயற்சி பண்றேன் நடக்கலியே!

வச : எதுக்கு? உயிரை வாங்கவா?

வைத் : சே...சே...ஆண்டவன் புண்ணியத்திலே உங்க ஆயுசும் நீடிச்சு... இந்த வியாதியும் நீடிச்சு... அடியேனுடைய உத்தியோகமும் நீடிச்சு இருக்கணும்னு சதா எமதர்மன் பிரார்த்தனை பண்ணிக்கிட்டேயிருக்கேன்.

வச : வைத்தியா! எமனுக்கு வாகனம் என்னடா?

விக : எருமைக்கடா! அதனாலேதான் கெட்டவுங்ககிட்டேயெல்லாம் மெதுவா வாரான்...

வச : ஆமாம்... சந்தேகமில்லே... சந்தேகமில்லே—

விக : வைத்தியரே... என் ஆழ்ந்த அனுதாபங்களை முதலில் தெரிவித்துக்கொள்கிறேன்...

வைத் : என்ன விகடரே...

விக : நிலையில்லா வாழ்வு... இதோ... புது வைத்தியர் வந்து விட்டார், வசந்தனுக்கு!

<!-- source: pdf=67 printed=66 status=verified -->

வைத் : அப்போ நான்...

விக : சற்றே விலகியிரும் பிள்ளாய்...

[அக்ஷயன் வடிவில் மனோகரன் வருகிறான்.]

வச : ஏ, புது வைத்தியா... உனக்கு என்னென்ன தெரியும்.

அட் : மருந்து கொடுக்காமலேயே ஒரு முடிவு கட்டுவேன் வியாதியை!

வச : அப்படீன்னா... நீதான் புது வைத்தியன் சந்தேகமில்லே... ஏ பழைய வைத்தியா நீ ஓடு...
