[பூஜை அறை]

உக் : இத்தனை விளக்குகள் ஏன் வசந்தி?

சேனா : ஏன் ஒரு விளக்கு போதுமா?

உக் : அதுகூடத்தேவை இல்லை, அணையா விளக்கு நீ அருகே இருக்கும்போது!

(அரசர் கதவை இடிக்கிறார். உக்ரசேனன் வாளை உருவுகிறான்.)

சேனா : வேண்டாம்! காரியம் கெட்டுவிடும். நான் பார்த்துக் கொள்கிறேன். இப்படி வாருங்கள்... (அறைக்குள் அனுப்பி கதவை மூடுகிறாள்; கதவு உடைபடுகிறது) யாரது?

அரசர் : யாரா?......பாதகி!

சேனா : ஆ! பிரபு! அடியாளைப் பார்க்கக் கூடாதென்று தாங்கள்? ஆண்டவன் கட்டளையாயிற்றே!

அர : எதடி ஆண்டவன் கட்டளை? எது? அர்த்த ராத்திரியிலே, ஹம்ஸ தூளிகா மஞ்சத்தில் அந்த ஆண்—

<!-- source: pdf=73 printed=72 status=verified -->

டிப் பயலோடு நீ ஆனந்தக் கேளிக்கை நடத்தவேண்டுமென்பதா ஆண்டவன் கட்டளை?

சே : ஆ! கண்ணால் கண்டதும் பொய்! காதால் கேட்டதும் பொய்! தீர விசாரிப்பதுதான் மெய், மஹாராஜா!

அர : சீ! நாடகமாடாதே! எங்கே அந்த ஆண்டி?

சே : அவர் தியான லோகத்தில் இருக்கிறார்

அர : உத்தியான லோகத்திலா? ஊர் கெடுக்கும் பதரே! இனியும் நீ புருஷோத்தமனை ஏமாற்ற முடியாது.

தோழி : மஹாராஜா! அமைதியாக ஆலோசனை செய்யுங்கள். அம்மாவை பழி கூறாதீர்கள். அவர்கள் உத்தமி!

அர : உத்தமிக்கு லக்ஷணம் உரைக்க வந்தவளே, உண்ட வீட்டிற்கு ரண்டகம் செய்யும் துரோக வடிவமே! உன்னால் வந்ததுதானடி இவ்வளவும். உயிர்விடப் போகிறாள்...... உடனே வந்து காப்பாற்றுங்கள் என்று அலறினாய்! உத்தமர் சத்தியசீலருக்கும், பத்தினி பத்மாவதிக்கும் களங்கம் கற்பித்தாய். அப்போதெல்லாம் தெரியாதடி நீ இந்தத் திருடியின் கன்னக்கோலென்று!

தோழி : மகாராஜா!

அர : உண்மையைச் சொல், நீயும் இந்த நாசக்காரியும் என்னை ஏமாற்றி வாழ்ந்தது உண்மைதானே? சொல்லடி! சொல்!

சே : அவளை ஒன்றும் செய்யாதீர்கள். எல்லாம் நானே சொல்லுகிறேன். கணவனுக்கு விஷம் கொடுத்துக் கொன்றேன். களங்கமற்ற பத்மாவதி கற்பிழந்தாள் என்று கதை கட்டினேன்.

அர : ஆ!

சேனா : என்னடா! உண்மையெல்லாம் சொல்கிறாளே என்று யோசிக்கிறீரா? இதையெல்லாம் சொல்லுவது உம்மிடம் மன்னிப்பு பெற அல்ல. இனி உம்மால் என்னை ஒன்றும் செய்யமுடியாது என்ற மனோ தைரியத்தில்!

அர : மோசக்காரி!

<!-- source: pdf=74 printed=73 status=verified -->

சே : மோசக்காரி! நானு மோசக்காரி? பல ஆண்டுகளாக என்னை பள்ளியறைப் பதுமையாக மாத்திரம் வைத்துக்கொண்டு என் பாலகனுக்கு பட்டாபிஷேகம் செய்ய வேண்டும் என்ற என் ஒரே ஒரு தணியாத ஆசையைக்கூட தரை மட்டமாக ஆக்கிவிட்ட நீரல்லவா மோசக்காரர்?

அர : உன் பாலகனுக்கு பட்டாபிஷேகம், மறந்துவிடு அதை! இந்த பூமியை புருஷோத்தமன் சந்ததியிடமிருந்து யாராலும் பறிக்க முடியாது.

சேனா : கனவு காண்கிறீர்! வாழ்த்துப் பத்திரம் தயார் செய்து வையும் - வசந்தனின் மகுடாபிஷேகத்திற்கு! கேசரிவர்மனின் புதல்வன் வசந்தனின் மகுடாபிஷேகத்திற்கு-

அர : நிறுத்தடி! நிறுத்து வேசி!

சேனா : பாவம்! அது இப்போதுதான் தெரிந்ததோ?

அர : பாவி! பரத்தை உன்னை உயிரோடு வைத்திருந்தால் உளறிக்கொண்டே இருப்பாய். யாரங்கே? ஓடி வாருங்கள்! இவளைப் பிடியுங்கள்.

[காவலாளிகள் அசையாமல் நிற்கிறார்கள்.]

சேனா : நடக்காது, அஸ்தமித்துவிட்டது உமது அதிகாரம். இவர்கள் என் வீரர்கள்! அக்ஷயா இவனைக் கைது செய்!

அர : ஆ என்னையா கைது செய்யச் சொல்லுகிறாய்?

சேனா : ஆம்; உன்னைத்தான். கைது செய்யச் சொல்லுகிறேன். அதுவும் இந்த கடைசி ராஜ உடையுடன்! அக்ஷயா! ஏன் நிற்கிறாய் அக்ஷயா? உம்............ நடக்கட்டும்.......

[தந்தையை மனோகரன் கைது செய்கிறான்]

அரசன் : (தனக்குள்) புருஷோத்தமா! புறமுதுகு காட்டியறியாத உன் பரம்பரையின் புகழை மண்ணோடு மண்ணாக்கிவிட்டாய்! வாளேந்திய உன் கரங்களிலே விலங்கு பூட்டிய விலங்கு! ஏ! வீரபூமியே! எனை மன்னிக்கமாட்டாயா?

(சிறைக்கூடம்)

மனோ : சிரமசைத்தால் சிற்றரசர்கள் கப்பமுடன் வணங்குவர் சேனைத் தளபதிகள் சீறி எழுவர். அந்த செங்கோல் சிங்கத்தின் ராஜரீகம் இன்று சிறைக்கம்பிகளுக்குள்ளடங்கி விட்டது.

அர : அட கோழைகளே! ராஜ விசுவாசமுள்ள வீரன் ஒருவன் கூட இங்கே கிடையாதா?

மனோ : இருக்கிறார்கள் அத்தனை பேரும் சிறைச்சாலையில் ரத்தச்செலவே இல்லாமல் கத்தி முழக்கம் கேட்காமல் வெற்றி முரசு கொட்டியிருக்கிறார் எங்கள் வேந்தர்.

அர : வேந்தன்! வேல் பிடிக்கத் தெரியாமல், கமண்டல மேந்தி களம் புகுந்த தபோதகனுக்கும் பெயர் வேந்தன்!

மனோ : அப்படியல்ல! உக்ரசேனன் புத்திசாலி! கட்டிலறையிலே இருக்கும் புருஷோத்தமரை எதிர்க்க, கணைகளோ, கேடயங்களோ தேவையில்லை என்று தெரிந்திருக்கிறார். ஆகவே காவி, கமண்டலங்களே போதுமெனத் தீர்மானித்திருக்கிறார்.

அர : போதுமடா நிறுத்து. வேசி வீசிய வலையிலே விழுந்துவிட்ட காரணத்தால் என் வீரம் வீண் போய் விடவில்லை.

மனோ : யார் வேசி? வசந்தசேனை பத்தினி! பத்தரை மாற்று தங்கம்.

அர : இல்லை, என் பத்தரை மாற்று தங்கத்தைத்தான் பாதாள சிறையிலே போட்டேனே! பாவி! பத்மாவதி! நீதான் பத்தரை மாற்று தங்கம், உன்னைப் பழி கூறிய பாதகனுக்கு சரியான பரிசு கிடைத்துவிட்டது. பத்மாவதி!

மனோ : வருந்திப் பயனில்லை. நாளை காலையிலே வசந்தனுக்குப் பட்டாபிஷேகம்.

அர : வசந்தன்! அந்த வஞ்சகியின் மகன் வக்கிர மூளைக்காரன். வளமார் எமது பூமியின் வருங்கால காவலன் ஐயகோ! மனோகரா! ஆளப் பிறந்த என் செல்வமே! உன்னை சாகத்துரத்திய சண்டாளனுக்கு சரியான தண்டனை கிடைத்துவிட்டது. மனோகரா! உனக்கும் உன் மாதாவிற்கும் கண்மணி விஜயாவுக்கும் எத்தனை இடை

<!-- source: pdf=76 printed=75 status=verified -->

யூறுகள் செய்தேன்! அதற்கெல்லாம் யாரிடம் மன்னிப்பு கேட்பேன்? நீ எங்கிருக்கிறாய் மனோகரா! ஆயிரம் குற்றங்கள் செய்திருந்தாலும் தந்தைக்கு ஆபத்து என்றால் தலைகொடுக்க ஓடிவருவாயே! உன்னிடம் யார் இந்தச் செய்தியையை சொல்லுவார்கள் மனோகரா! மனோகரா நீ எங்கிருக்கிறாய் மனோகரா!

மனோ : இங்கே தான்!

அர : எங்கே? என் மனோகரன் எங்கே? எங்கே மனோகரன்? மனோகரா! மனோகரா!
