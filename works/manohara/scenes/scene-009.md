[வசந்தசேனை அந்தப்புரம். வசந்தசேனை ஆத்திரமுடன் எழுந்து உலவுகிறாள்...
வீரர் இருவர் வருதல்......]

வசந்தி : எங்கே...நாடகக் கும்பல்?

வீரன் : விரட்டிக் கொண்டே போனோம். தப்பிவிட்டார்கள்......

வச : தைரியசாலிகள்! வெட்கமில்ல. சீ ஓடுங்கள்......

தோழி : ஏம்மா...நாடகக்காரர்கள்;

வச : ஆம்?......பரிசு கொடுக்க!.....

தோழி : கொடுக்க வேண்டியதுதாம்மா...நம்மை காட்டி கொடுக்கிற கதையா இருந்தாலும் நடிப்பு நல்லா இருந்தது!

வச : சீ...என்னடி விமர்சனம்...போடி! உம்!

(தனக்குள்) நாடகம்...என்னை வைத்து எழுதப்பட்டது! கேசரி வர்மன் உயிரோடு...சேச்சே, பிணம் பிழைப்பதாவது...ஒரு வேளை...விஷம் சரியாக வேலை செய்யாமல்......

(அரசர் வருகிறார்.)

வச : ப்ரபூ!

(அசட்டு சிரிப்புடன் அரசன் உட்காருதல்.)

வச : வழக்கமான புன்சிரிப்பு இல்லே...வாட்டத்தோடு இருக்கிறீர்கள்...என்ன காரணம், ஸ்வாமி?......

அர : ஒன்றுமில்ல...

வச : பிறகேன், கண்ணே என்ற கனிமொழி உதிரவில்லே? கண்களிலே கலக்கம்...கண்ணாளா! பால்!...

அர : பாலா?...

<!-- source: pdf=20 printed=19 status=verified -->

வச : ஏன், ஓஹோ! நாடகம் நினைவுக்கு வந்துவிட்டதோ...

அர : அதெல்லாமில்ல...

வச : பெருமூச்சால் பேசுவானேன் என்னையே கேளுங்கள் என் கணவர் கேசரி வர்மன்...நம் காதலை காண சகிக்காமல் ஊரைவிட்டு ஓடிவிட்டார் என்று தங்களிடம் சொல்லியிருந்தேன்...

அர : ஆமாம்! இப்போது???

வச : நஞ்சு கொடுத்துத் தன் கணவனைக் கொல்லுகிறாள் நாடக தேவசேனா! தாங்களும் அதை உண்மையென்று நம்பி......

இரண்டு கிண்ணங்களையும் கையில் எடுத்துக் கொண்டு...”இதில், எதை வேண்டுமானாலும் தாங்கள்...”

அர : வேண்டாம்...நீயே கொடு...

வச : இல்லே தாங்கள் விரும்புவதை எடுத்துக் கொள்ளுங்கள். சந்தேகம் ஒரு சங்கடமான நோய். காதல் வாழ்வை துண்டாக்கும் கட்டாரி...அது வீரனையும் கோழையாக்கும்...உம், எடுத்துக் கொள்ளுங்கள்... (பிறகு யோசித்து)... அதுகூடவேண்டாம்... நானே இரண்டையும் சாப்பிடுகிறேன்.

(ஆச்சரியமாய்)......

வசந்தி : என்னை மன்னித்துவிடுங்கள் மகாராஜா? பதின்மூன்று ஆண்டுகளாக தங்கள் பத்தினியாக வாழ்ந்தேன் - அதை வைத்துக் கேட்கிறேன். ஆபரணம் - ஆடம்பரவாழ்வு - அரச போகம் - போதும்... தாருங்கள் தயவு செய்து...காஷாய உடை! கையிலே ஒரு ஓடு! மறுக்காதீர்கள். போக விடை கொடுங்கள்......

அர : போவதா......நீயா?......எங்கே கண்ணே......

வச : உலகம் மிகப் பெரியது. பிரபு! அதன் ஜனக் கூட்டத்திலே நானும் ஒரு துளியாக விடுகிறேன் - தங்கள் பெயரை ஜபித்துக்கொண்டு என் ஜன்மத்தை கழித்துவிடுகிறேன்.

<!-- source: pdf=21 printed=20 status=verified -->

வச : உங்கள் காலடியில் கிடக்கும் என் இன்ப வாழ்வுக்கு தீ மூட்டத் திட்டம் போட்டு விட்டார்கள்!

அர : திட்டம்? யார்?

வச : மகாராணி தான்!

அர : யார்... பத்மாவதியா?......

கேசரியின் குரல் : இல்லே...பச்சைப் புளுகு?...பாராளும் வேந்தே...பாகு மொழியில் பலியாகாதே!

வச : பாருங்கள் ஸ்வாமி பாருங்கள்...... நான் கேள்விப்பட்டது உண்மைதான்...... மகாராணி மந்திராலோசனை வேறு நடத்துகிறார்களாம்...... உங்களிடமிருந்து என்னைப் பிரிக்க......

அர : கவனிக்க வேண்டியதுதான்! (காவலரிடம்) யார் இங்கு பேசியது என்று தேடிப் பாருங்கள்.

(சிப்பாய்கள் சப்தம் வந்த திசை நோக்கி ஓடுகிறார்கள்)

மனோகரன் : புரையோடி விட்ட புண்ணுக்கு புனுகுப்பூச்சு பொல்லாங்குக்காரியின் போலி வேடத்தைப் பொசுக்க பொறுமை......... போதுமம்மா பொறுத்ததெல்லாம், உத்திரவு கொடுங்கள். உருத் தெரியாமல் ஆக்குகிறேன் அந்த ஊர் கெடுப்பவளை!

பத்மா : மனோகரா! இரு......

(அங்குள்ள பெட்டியிலுள்ள வாள் மனோகரனிடம் கொடுக்க)

மனோ : அம்மா! (வாள் வீச்சு) வேஷக்காரி வசந்தா தொலைந்தாள்!

பத : பொறு செல்வா...

அதைவிட ஒரு புனிதமான காரியத்தில் உன்னை ஈடுபடச் சொல்கிறேன்.

மனோ : என்னம்மா அது?

பத்மா : இந்த வாள் ஏது தெரியுமா?......

மனோ : நாடகத்தில் கூட இதுமாதிரி ஒரு வாள்...ஆமாம் பார்த்தேன்......
