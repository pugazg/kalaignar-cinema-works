[நந்தவனம்]

வசந்தி : வந்துவிட்டீர்களா ஸ்வாமி, நான் சோலைப் பாறையில் காத்துக் கிடந்தேன்—தாங்கள் மாளிகை வழியே வந்திருக்கிறீர்கள்.

அர : வழி, எதுவானால் என்ன... உன் மொழியிலே, தேன் விழியிலே ஒளி மாறிவிடுகிறதா வசந்தி!

வச : எப்படி மாறும்—இந்திரனுக்காகப் படைக்கப்பட்ட அகல்யா—சந்திரனுக்காகப் படைக்கப்பட்ட தாரை—புருஷோத்தமருக்காகப் படைக்கப்பட்ட வசந்தா—

<!-- source: pdf=62 printed=61 status=verified -->

அர : வசந்தி! கண்ணே... உன்னோடு என்ன பேசுவதென்றே தெரியவில்லை—

வச : ஊமையாகவே இருங்கள்—அந்த ஒய்யாரத்தை நான் ரசிக்கிறேன்...

அர : இப்போது... நீ எது கேட்டாலும் கொடுப்பேன்—

வச : வந்தது ஆபத்து!... நான் கேட்பதாக நினைத்ததைக் கூட இப்போது கேட்கப் போவதில்ல...

அர : ஏன் வசந்தி!...

வச : சமயம் பார்த்து கேட்கிறாள் சாகசக்காரி என்பீர்கள் நானென்ன தசரதனை ஏமாற்றிய கைகேயியா?... வேண்டாம்... வேண்டாம்...

அர : என்ன வசந்தி, கேள்!...

வச : வேண்டாம்... ஹூம்!...

அர : சரி... நான் போகிறேன்...

வச : அய்யோ!... என் உயிர் போய்விடும்—உட்காருங்கள்

அர : பிறகு... சொல்லேன்...

வச : மனோகரன் நாட்டை விட்டுப் போய் விட்டான்...

அர : அதையேன் கிளறுகிறாய்...

வச : இல்ல...இளவரசன் இல்லாத நாடு... எழிலில்லாத ஓவியம் போலத்தானே!...

அர : அதற்கென்ன செய்வது...

வச : ஏன், நம் வசந்தனை இளவரசனாக்கிவிட்டால்...

அர : பைத்தியம்! வசந்தனைவிட நீ பெரிய பைத்தியம்!...

வச : ஸ்வாமி...

அர : அவனை இளவரசனாக்கக் கூடாது!... பைத்தியக்காரனுக்குத் தீர்க்கதரிசியாக பட்டம் கட்ட வேண்டும்—அவனுக்கு முடி சூட்டினால்.... முதலில் நீ பைத்தியம்—பிறகு நான் பைத்தியம்—அப்புறம் இந்த நாடே பைத்தியம்...

வச : போதும்... போதும்!... வர்ணிக்காதீர்கள்—வசந்த ராஜனுக்கு இதுவும் வேண்டும் இன்னமும் வேண்டும் உன்னை... அறிவாளி என்று நினைத்தேன்... [கோபமாக] நீ ஒரு ஞான சூன்யம்!

<!-- source: pdf=63 printed=62 status=verified -->

வச : (தந்திரமாக) முட்டாள் என்று மூவாயிரம் முறை சொல்லுங்கள்—சந்தோஷம்!... ஆனால்... உங்கள் வசந்தி வஞ்சகி என்று மாத்திரம் நினைக்காதீர்கள்... ஸ்வாமி!... ஒரு யோசனைதான் உங்களைக் கேட்டேன்— என் மகன்மட்டு மல்லவே அவன்—தங்கள் மகனுந் தான்—தங்களை விட எனக்கென்ன ஆசை வந்து கிடக்கிறது! என் லட்சியம் தங்கள் சுகம்... சுயநலமல்ல...

அர : எனக்குத் தெரியாதா கண்ணே! ஆனால் வசந்தன்!

வச : அந்த பேச்சு வேண்டாம்—விபரீதப் பேச்சு!... பைத்தியத்துக்கு பட்டம் சூட்டினால்... என்ன ஆகுமென்று எனக்கும் தெரியும்... உங்களை கிண்டல் செய்தேன். நீங்கள் அதற்குள்.... ஹூம்!

அர : வசந்தி!...

வச : ப்ரபூ!...நிலாமுற்றம் தேடுகிறது—வாருங்கள்...

வசந்தசேனை மனதிற்குள் : “இனி புருஷோத்தமனை நம்பி புண்யமில்லை—புதிய திட்டம் போடவேண்டும். நன்றி கெட்ட இந்த ராஜனை நாடு கடத்த வேண்டும்... மனோகரனைக் கொல்ல வேண்டும்... வசந்தனுக்கு பட்டம் கட்ட வேண்டும். இதற்கெல்லாம் உதவி செய்யக் கூடியவன் என் பழைய காதலன் உக்ரசேனன் தான்”

வசந்தசேனை அறைக்குள் போகிறாள். வசந்தன் பின் தொடர்கிறான்.

[வசந்தசேனை கடிதம் எழுதுகிறாள். அரூபம் பின் தொடர்கிறது, வசந்தசேனை நடுங்கிக் கொண்டு.]

வ. சே : யாரங்கே! ஒரு கொடியவன் உள்ளே ஒளிந்திருக்கிறான். விடாதீர்கள் அவனை!

[அரூபம் வசந்தனை அழைக்கிறது]

வச : நீ பிசாசா? கடவுளா?

அரூபம் : இல்லை வசந்தா... நான் மனிதன்.

வச : மனுஷனா? என் கண்ணுக்கு தெரியலையே.

அரூ : தெரியமாட்டேன்! என் அய்யன் குருநாதன் அருள் அறிவின் விளைவு. ஒரு மருந்தின் வேலை,

வச : அந்த மருந்தை எனக்கு கொஞ்சம் தர்ரியா?

<!-- source: pdf=64 printed=63 status=verified -->

அரூ : தருகிறேன்! ஆனால் நீ நான் சொல்றபடி கேட்க வேண்டும்.

அரூ : முதலில் ஒரு சிப்பாயை வரச் சொல்...

[விகடன் அழைக்க சிப்பாய் ஒருவன் வருகிறான். அரூபம் அவனைக் கட்டிப் போட்டுவிட்டு நழுவுகிறது]

[வசந்தசேனை கடிதம் எழுதி அதைக் கூட்டிற்குள் போடுகிறாள்]
