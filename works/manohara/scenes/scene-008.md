(அரண்மனையில் நாடகம், கேசரிவர்மன் திரைக்குப்--பின்னாலிருந்து பேசுகிறான்)

: கற்பனைக் கதையல்ல நீங்கள் காணப்போவது சிந்தனைச் சித்திரம். சிங்காரியால் சீரழியும் ஓர் சாம்ராஜ்ய சரித்திரம்!

: வேந்தன் உத்தம புருஷன் ஒரு செந்தமிழ்ச் சோலை.

அவன் சிந்தை குளிப்பாட்டிய தென்றல் கமலாவதி, பட்டத்தரசி!

: பட்டத்தரசியின் தந்தையை பாண்டியன் கொன்றான். நெஞ்சை குலுங்கும் செய்தி ஏந்தி வந்தான் ஒரு சைத்ரிகன் ஈஸ்வரி வர்மன்!

அவன் மனைவி தேவசேனா ஒரு சித்ராங்கி.

: தென்றல் போல வந்தாள்.

புயலாக மாறினாள். அந்தப் புன்சிரிப்புப் புயல் புகுந்த கட்டம்...

(நாடகம் துவங்குகிறது)

கமலாவதி : அப்பா!... அப்பா...!

உத்தம புருஷன் : அழாதே கமலா அழாதே!

வர்மா : மாமா தமது அந்திய காலத்தில் சொல்லிய செய்தி ஏதாவது?...

ஈஸ்வரி வர்மன் : இருக்கிறது ப்ரபூ...

: “என் பேரன் அஜயன் தான் பாண்டியன் மீது பழி தீர்த்துக்கொள்ளவேண்டும். என் நவரத்ன சிங்காதனத்தை மீட்பதும் அவன் பொறுப்புதான்.

<!-- source: pdf=14 printed=13 status=verified -->

இந்த பழி தீர்க்கும் பாரம் ராஜா உத்தம புருஷனுக்கு கிடையாதென்பதையும் திட்டமாக கமலாவதிக்கு தெரிவித்து விடு...

மகாராஜாவிற்கு என் மனப்பூர்வமான ஆசீர் வாதம்”—இதுதான் மஹாராஜா, தங்களுக்குத் தங்கள் பிதா கூறிய செய்தி... கடைசியாக இந்த வார்த்தை தங்களிடம் கூறிச் சொல்லியதும் மஹாராஜாவின் உயிர் அமைதியாகப் பிரிந்து விட்டது,

உத் : அப்பா......!

கம : அப்பா......?

அஜயன் : அம்மா......!

கம : அஜே......!

அஜ : எம்மா அழறே!

கம : இல்லேடா கண்ணு. அஜயா உன் தாத்தாவைக் கொன்ற அந்த பாண்டியனை...

அஜ : கொடம்மா கத்தி.....

: அவன் தலையை இப்பவே வெட்டி கொண்டாறேன்,

கம : ஆம் அதில் சந்தேகமே இல்லையடா

: பெரியவனானதும் நீ நிச்சயமாய் செய்வாய்...!

(நாடகம் பார்த்துக்கொண்டிருக்கும் பத்மாவதி பக்கத்திலிருக்கும் மனோகரன்மீது கைவைக்கிறாள்.)

மனோ : என்னம்மா...?

பத் : ஒன்றுமில்லையடா கண்ணே! நாடகம்...

(நாடகத்தில்)

வர்மன் : அப்போது எனக்கு விடை!

உத் : வர்மரே! நீர் நமது அரண்மனையிலேயே தலைமைச் சைத்ரிகராக இருக்கவேண்டும்.

வர் : என் பாக்கியம் ப்ரபூ!

<!-- source: pdf=15 printed=14 status=verified -->

கம : உன் மனைவிக்கு இஷ்டமிருந்தால் அவள் என்னிடமே பணிப் பெண்ணாக இருக்கலாம்.

வர் : எங்கள் பாக்கியம் தாயே!

தேவசேனா : (தனக்குள்) பணிப்பெண் நான், பாராளும் மகாராணி இவள்! நாளை காலம் மாறினால்...!

(நாடகம் பார்த்துக்கொண்டிருக்கும் விகடன்.)

: அம்மா! அம்மா! இவ பலே ஆள்தான்!...

சத்யசீலர் : இப்படித்தான் ஒரு சைத்ரிகன் வந்தான் அரண்மனைக்கு... பதினெட்டு ஆண்டுகளுக்கு முன்பு...

ராஜப்பிரியன் : அவன் பெயர்?

சத் : கேசரி வர்மன்!

(நாடகத்தில் தேவசேனா அரசன் உத்தம புருஷன் மயங்கும்படி நடனமாடுகிறாள். அரசன் ஒரு முத்துமாலையைப் பரிசாகத் தருகிறான்.)

(தேவசேனாவிடம்)

வர்மன் : உனக்கு ஒரு சந்தோஷச் செய்தி! நமது நாட்டு கலாமந்திரத்தை உத்தேசித்து தட்சிணப் பிரதேசம் முழுவதும் நான் சுற்றுப் பிரயாணம் செய்யவேண்டி இருக்கிறது. அது மகாராஜாவின் ஆணை!

தேவசேனா : எனக்கு அது சந்தோஷச் செய்தி! ஹும்! அட ராஸ்கல்!

வர்மன் : அவசரம்தானே கூடாது... உன்னையும்தான் அழைத்துப் போகப் போகிறேன்......

சேனா : நிஜந்தானா அத்தான்...... இப்பத்தான் நீங்கள் என் பொன்னத்தான்!... அப்பா!... கூண்டுக் கிளி மாதிரி இதுவரை காலம் தள்ளி வந்தேன்... அத்தான்—இதோ... மஹாராணியிடம் உத்தரவு கேட்டு வந்து விடுகிறேன்.

(சொல்லியபடி கீழே விழுகிறாள்)

<!-- source: pdf=16 printed=15 status=verified -->

தோழி : அம்மா!... அம்மா!...... சொன்னு கேட்டாத் தானே!......

வர்மன் : சேனா!

தோழி : மறுபடியும் மயக்கம் வந்திடுச்சுங்களா?......

வர்மன் : அப்போது இதற்கு முன்பும்?......

தோழி : என்னங்க எஜமான்... தெரியாத மாதிரி பேசாதீங்க. அம்மா!... இன்னும் ஒன்பது மாசத்திலே ஒரு குழந்தைக்குத் தாயாகப் போகுது

வர்மன் : ஆஹா... சேனா கர்ப்பிணி.

நாடகம் பார்க்கும் ராஜப்பிரியன் : அப்படியானால் வசந்தன் யார் மகன்?

சத்யசீலர் : நாடகத்தைப் பார்!

ராஜப் : நாடகமா? நடந்ததா?

நாடகத்தின் அடுத்த காட்சியாக அரசன் உத்தம புருஷனும் தேவசேனாவும் காதல்பாட்டு (நிலாவிலே! சல்லாபமே!! பாடுகின்றனர்.)

கமலாவதி : உம்...நகரசோதனை இன்று சீக்கிரத்தில் முடியவில்லை போலிருக்கிறது........

ராஜா : ஆம்...ஆம்...நேரந்தான் ஆகிவிட்டது...வழியில் எதிர்பாராத ஒரு வேடிக்கை......

கமலாவதி : வேடிக்கையாகத்தானிருக்கிறது உங்கள் பேச்சும்... இங்கு நான் விழித்துக்கொண்டிருப்பதுகூட உங்களுக்கு எதிர்பாராத ஒரு வேடிக்கையாகத்தான் இருக்கிறது...ஸ்வாமி...... நகரசோதனைக்கா இந்த நாகரீக உடைகள்?... நல்ல வாசனை!...ஜவ்வாதுப் பெட்டி!...ஓ!...மாப்பிள்ளை மணவறையிலிருந்து இப்போதுதான் திரும்புகிறீர்கள் போலிருக்கிறது... தங்களின் புது மணமகள் யார்தான் ஸ்வாமி?...

ராஜா : நாவை அடக்கிப் பேசு...போ அப்புறம்—

கமலா : உங்கள் நாவு இவ்வளவு கேவலமாகவா மாசு விட்டது. அந்த சண்டாளியின் சகவாசம்.

<!-- source: pdf=17 printed=16 status=verified -->

(ராஜா கமலாவதியை கன்னத்தில் அறைகிறார்)

கமலா : மகாராஜா! தர்க்க நியாய வாதங்களுக்குப் புறம்பாக தான்தோன்றி முறையில் பேசி அகாரணமாக என்னை அடித்து புண்படுத்திவிட்ட உங்களை நான் இனிப்பார்க்கத் தயாராக இல்லை, உங்களைக் காணவும் என் கண் கூசுகிறது. வேசி தேவசேனையின் நேசத்தின் வேகம் தணிந்தபின் தாங்களாக வந்து என்னைப் பார்த்தாலொழிய நானாக வந்து தங்களை பார்க்க மாட்டேன்— என்பதையும் நன்றாக ஞாபகத்தில் வைத்துக் கொள்ளுங்கள். மகாராணி கமலாவதிக்கு உங்கள் புதிய ரதிதேவியின் அழகில்லாமலிருக்கலாம். ஆனால் அவளின் இந்த மஞ்சள் கயிற்றுக்கு ஒரு தனி மகிமை உண்டென்பதைமட்டும் உணரும் காலம் உங்கள் வாழ்க்கையிலே ஒருநாள் நிச்சயம் வந்தே தீரும். போய்வாருங்கள், உங்கள் புண்ணிய சேவைக்கு! போங்கள்.

ராஜா : நீ சொல்லவேண்டாம்! நானே போய்க்கொண்டுதான் இருக்கிறேன்.

தேவசேனா தோழியிடம்.

சேனா : இந்தப் புள்ளிதான் அடையாளம்... இதில் போடு விஷத்தை. பத்திரம்......

நாடகம் பார்க்கும் வசந்தசேனா:

மகாராஜா! இனிமேல் என்னால் இருக்கமுடியாது... உள்ளம் கொதிக்கிறது.

நாடக தேவசேனா : அத்தான்...சூடான பால்... தலைவலி பறந்துவிடும்......

வர்மன் : சேனா கர்மக் கள்ளிகள் தங்கள் கணவன்மார்களுக்கும் பாலில் விஷம் கலந்து கொடுப்பார்களாம். நீ கேள்விப்பட்டிருக்கிறாயோ

சேனா : இல்லையத்தான்...ஆனால் இந்தப் பாலில் அப்படியொன்றுமில்ல

வர்மன் : நீ சொல்லும்போது எனக்கென்ன பயம்? சேனா இப்படி வா...... என் கையால் உனக்குப் பாலைக் கொடுத்து ரொம்ப காலமாயிற்றல்லவா?........

சேனா : ஆமாம்...அதெல்லாம் கலியாண புதிதில்...

வர்மன் : சீ...அப்படிச் சொல்லாதே...குடி...

சேனா : தேவாமிர்தமாயிருக்கிறதத்தான்!......

வர்மன் : சரி... அதைக் கொடு. நானே குடிக்கிறேன்.

சேனா : ஏனாம்... நான்தான் கொடுப்பேன்... உம்...

நாடகம் பார்க்கும் வசந்தன்:

வேண்டாம்! வேண்டாம் விஷம்!”

சேனா : ஹா ஹா ஹா...விஷம் வேலை செய்கிறதாக்கும்... புத்திசாலிகளின் போக்கே இப்படித்தான்......

வர்மன் : அடீ...ராக்ஷசி!...சோரம் செய்தது போதாதென்று சொந்தப் புருஷனையும் மருந்திட்டுக் கொல்லுகிறாய்? ஆ.........

சேனா : உன்னால் நான்பட்ட துன்பங்கள் ஒன்று, இரண்டா? என் உயிர்க் காதலன் ருத்ரசேனனிடமிருந்து என்னைப் பிரித்தாய்? இப்போது என் கருத்து பூத்துக் காய்த்து கனியாகும் நிலையிலிருக்கிறது...உன்னை உயிரோடு வைத்திருந்தால் வேறையல்லவோ வெட்டிப் போடுவாய்? அதனால்தான் நான் முந்திக்கொண்டு விட்டேன்...உன் தலைவிதியைத் தடுக்க யாரால்தான் முடியும்? மனைவியின் மனதறிந்து நடக்கத் தெரியாத மடையன்களுக்கெல்லாம் இதே கதிதான் எந்தக் காலத்திலும்......

வர்மன் சாகிறான், நாடகம் காணும் வசந்தசேனை கூச்சலிடுகிறாள் நிறுத்தச் சொல்லி!
