அரண்மனை.

சிப்பாய் : மகாராஜா! அக்ஷயன் வந்திருக்கிறார். பார்க்க வேண்டுமாம்.

வ. சே : வந்துவிட்டானா?...இங்கே வரச்சொல்.

: வெற்றிச் செய்தியோடு வந்திருப்பான். விஜயாவின் குழந்தையைக் கொன்று விட்டுவந்திருப்பான். அவனுக்காக இந்தப் பரிசு

: உங்கள் தளபதி மிகவும் தந்திரசாலி.

உக்ரசேனன் : அதில் சந்தேகமென்ன? ஓ... வா... அக்ஷயா வா...

: என்ன அக்ஷயா? [உண்மை அட்சயன் வருகிறான்]

சேனா : யார் இவரு அக்ஷயன்?

உக் : ஆமாம்.

சேனா : ஆ! இல்லை.

அட்சயன் ; நான் தான் உண்மையான அக்ஷயன், உங்களை இது வரை ஏமாற்றியது போலி அக்ஷயன் அம்மணி!

: ஆமாம்...மகாராஜா! என்னைக் கட்டிப் போட்டார்கள். இப்போதுதான் தப்பி வந்தேன்.

உக் : கட்டிப் போட்டார்களா? யார்?

அட் ; மனோகரன்!

சேனா ; ஆ! மனோகரன்! அப்படியானால் இங்கு இருக்கிற அக்ஷயன்?

அட் : மனோகரன்!

உக் : எங்கே அவன் இருக்கிறான்......

சேனா : சிறைச்சாலைக்குத் தான் போயிருக்கிறான்.

உக் : விடக்கூடாது.
