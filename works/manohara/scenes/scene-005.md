(குகையின் உட்புறம்)

பெரியவர் : எங்கே கேசரி வர்மா அவசரமாகப் புறப்பட்டு இருப்பாய்?

கேசரி வர்மன் : நாடகத்திற்கு - அதோ அவர்களைத்தான் ஏற்பாடு செய்திருக்கிறேன்.

பெரி : மறந்துவிட்டேன். இன்று மனோகரன் பிறந்த விழாவா? உம் ... நாடகத்திற்கு என்ன பெயர் வைத்திருக்கிறாய்?

கேசரி : போர்வாள்.

பெரி : சபாஷ் ... தடையொன்றும் கிடையாதே நடத்துவதற்கு?...

கேச : கிடையாது. காரணம், கதை அவர்களுக்குப் புரியாது...

பெரி : வசந்த சேனைக்கு உன் நாடகத்துப் புனைப்பெயர் என்ன?

கேச : தேவ சேனா!

பெரி : உன் பெயர்?

கேச : ஈஸ்வரி வர்மன். புருஷோத்தமனை உத்தம புருஷனென்று மாற்றியிருக்கிறேன்.

பெரி : கட்டாயம் புரிந்துகொள்வார்கள் கதையை.

கேச : புரியத்தானே வேண்டும். அப்போதாவது புருஷோத்தமனுக்கு புத்தி வராதா?

பெரி : உம்... முயற்சி செய்து பார்!

கேச : வருகிறேன், குரு தேவா!

பெரி : ஜாக்கிரதை
