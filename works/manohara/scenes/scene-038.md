(சிறைச்சாலை)

விஜயா : வாள் முனையால், தன்னுயிரையும் மன்னுயிரையும் காத்திடும் வலிமை வாய்ந்தவர் கடைசியில் தப்பி ஓடி உயிர் பிழைத்தார். எல்லாம் உங்கள் நல்லெண்ணத்தால் வந்த நாசந்தான் அத்தே! அவர் எங்கு சென்றாரோ? எப்படி அலைகிறாரோ!

பத்மாவதி : சாப்பிடு விஜயா...

விஜயா : வேண்டாம் அத்தே!

பத் : கர்ப்பவதி சாப்பிடாமல் இருக்கக் கூடாது. வயிற்றில் வளரும் கருவுக்காகவாவது சாப்பிட்டுத்தானே ஆகவேண்டும்... சாப்பிடு...

விஜயா : அத்தே... இந்தக் கஞ்சியா...

* * *

வ. சே : அருமையாயிருக்கிறது...

தோழி : இந்தப் பழரசம் உடம்பைப் பளபளப்பாக்கும்...

வ. சே : தெரிந்துதானடி இதைத் தேர்ந்தெடுத்தேன், மாலினி! எங்கேயோ ஒரு அழகி இருந்தாளாம்; அவள் மேனியின் மெருகு குலையாமலிருக்க கழுதைப் பாலிலே ஸ்நானம் செய்வாளாம்.

தோழி : இதென்னம்மா அதிசயம்... நீங்கள் கேட்டால் புருஷோத்தமர் புலிப்பால் கூட கொண்டு வருவாரே...

வ. சே : சந்தேகமென்னடி அதிலே?

தோழி : அதிருக்கட்டும்... நீங்கள் இப்படி அலட்சியமாக இருக்கிறீர்களே... மனோகரன் வேறு தப்பிவிட்டான். வசந்தன் முடி சூட்டு விழாவை சீக்கிரம் நடத்திவிட வேண்டாமா?

வ. சே : இது என்னடி பெரிய காரியம், வேந்தனின் வேத புத்தகமே நான்தான். வெண்ணிலவை சூரியன் என்றால் அவர் நம்பித்தான் தீருவார்... கவலைப்படாதே! ஒரு கண்ணசைவில் முடிந்துவிடும் வசந்தன் பட்டாபிஷேகம்!

* * *

வைத்தியர் : ராஜாதி ராஜ... ராஜமார்த்தாண்ட...

விகடன் : ராஜ கம்பீர... ராஜகோலாஹல...

வைத் : ராஜவீர தீர பராக்கிரம...

விக : ரணரங்க தீர வீர சூர...

வைத் : உப்பில்லாம கலக்கஞ்சி குடிக்கும் வசந்த மகா ராஜா பராக்! பராக்!

வசந் : தோம்... தோம்... வந்தோம்......

விகடன் : வசந்தா! இதோ பாரு... அம்மா திட்டுவாங்க எழுந்திரு... தர்பார் மாதிரியே இருக்கணும்... நான் சொல்றபடி செய்யணும்... உம்... இதிலே உட்காருங்க மகாராஜா!

: இப்ப நான் சொல்றபடி சொல்லணும்......

விக : இப்ப நீங்க யாரு?

வசந்தன் : இப்ப நீங்க யாரு?

விக : த்ச்...பதில் சொல்லுங்க...

வச : த்ச்...பதில் சொல்லுங்க...

விக : அடடா... பதில் சொல்லுங்க, மகாராஜா?

வச : அடடா... பதில் சொல்லுங்க மகாராஜா!

விக : பதில் சொல்லணும் “மகாராஜா” அப்படீன்னு!

வச : உம்... சரி...சரி... மகாராஜா!

விக : ஆ... நான் தான் மந்திரி!

வச : உம்...

விகட : இவரு (வைத்தியரைக் காட்டி)

வச : தெரியும்... தெரியும்...... மகாராணி...... வா...வா... உக்கார...

விக : மகாராஜா... அவரு சேனாதிபதி...... இப்ப யாரு மகாராணி?

வைத் : அதோ...மாலினியை வைச்சுக்கலாம்...வா...

விக : (மாலினியைப் பார்த்து) நான் சொல்றபடி கொஞ்சம் கேளேன்... இன்னைக்கு மட்டும் நீ மகாராணி... மகாராஜாவோட போயி உட்காரு...

வச : [இளிக்கிறான்]... சபாஷ்....

விகடன் : அடுத்து நாட்டு அரசர் யாராவது, சந்தோஷமாக வந்தால் சந்தோஷமாக பேசவேண்டும், கோபமாக வந்தால் கோபமாக பேச வேண்டும்...

வச : சரி!... மந்திரி!...

விக : உம்—தர்பார் ஆரம்பமாகலாம்....

வச : சேனாதிபதி! நடனம் நடக்கட்டும்...

வைத்தியன் : மகாராணியை ஆடச் சொல்லுங்கள்...

விக : ஆமாம் அரசே! வேற ஆளில்ல பாருங்க... அதனாலே ஆடட்டும்!

[மாலினி ஆடுகிறாள்]

வச : உம்... ஆடு! நம் நாட்டில் எல்லோரும் சமத்துவம்... எல்லோரும் ஆடலாம்... நடனமாடத் தெரியாதவர்கள் பெண்களே அல்ல! சரிதானே விகடா

விக : இப்போது பெண்கள் நடப்பதே ஒரு நடனமாதிரிதானே இருக்கு!

[புருஷோத்தமர் வருகிறார்]

வச : ஓகோ! அடுத்த நாட்டு அரசரா?... சந்தோஷமாய் வருகிறீரா? கோபமாய் வருகிறீரா?...

புருஷோத் : போதுமடா... சும்மா இரு...

வச : ஓ! கோபமாய் வந்திருக்கிறார்... ஓய்!...மூளையில்லாத ராஜே!... முட்டாள் அரசரே!... எங்கே வந்தீர்? வந்த காரியத்தைச் சொல்லும்... வசந்தனுடைய தர்பாரிலே வரக் காரணம் என்ன?... மந்திரி!... போதுமா கோபம்!...

அரசர் : ஏ, விகடா இது என்னடா கூத்து!...

விக : முடிசூட்டு விழா... ஒத்திகை நடத்திக் காட்டச் சொன்னார்கள் அம்மா!...

அர : வைத்தியா! நீ என்ன மருந்து கொடுத்து பைத்தியத்தை தெளிய வைக்கிறாயா இல்லை!...

வச : பைத்தியமா?... யார் சொன்னது? இது தீராத வியாதி!...
