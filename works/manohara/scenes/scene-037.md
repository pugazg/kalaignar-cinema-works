(அரண்மனை)

காவலாளி : மகாராஜா! இளவரசர் தப்பிவிட்டார்.

அரசர் : என்ன?

வ. சே : ஆ! மனோகரன் தப்பிவிட்டானா?

காவலாளி : ஆமாங்க... யாரோ கட்டுகளை அவுத்து காப்பாற்றினார்கள், கண்ணுக்கே தெரியவில்லை.

வ. சே : விபரீதம்வளர ஆரம்பித்துவிட்டது பிரபு! நகர் முழுவதும் சோதனை போடுங்கள், அந்த நாசகாரன் எங்கிருந்தாலும் பிடித்து வாருங்கள்.

அரசர் : உம்...போங்கள்.

[குகை : மனோகரன் மயக்கம் தெளிந்து கண் விழிக்கிறான்.]

மனோகரன் : முடியாதும்மா... முடியாது... (சுற்றிலும் பார்த்தபடி) என்ன இது... கொல்லப்பட்ட நான் உயிரோடு...

கேசரிவர்மன் : இளவரசே!

மனோ : யார் நீ... நீ யார்... சத்யசீலரே! யார் இவன்?

சத்யசீலர் : விபரம் பிறகு சொல்கிறேன்... அவன் தான் உன்னைக் காப்பாற்றியவன்.

மனோ : என்னைக் காப்பாற்றுவது...... மனோகரனைக் காப்பாற்றுவது... மன்னன் ஆசை... மாதாவின் அன்புக் கட்டளை.... இவைகளை உடன் நிறைவேற்றுங்கள்... கொல்லுங்கள்... என்னைக் கொல்லுங்கள்... கொல்லுங்கள் ராஜப்பிரியா! என் அன்புத் தோழா... என் அன்னையின் கட்டளையை நீயாவது நிறைவேற்று.

சத்ய : பொறு மனோகரா!

ராஜப் : மனோகரா... தாய்ச்சொல் தவறக் கூடாது என்பதற்காக சிறை வாசத்திலிருக்கும் தாயை அனாதையாகச் சாகவிடுவதா?

மனோ : ஆ! அம்மா சிறையில்...

ராஜப் : அம்மா மட்டுமல்ல... விஜயா கூட...

மனோ : ஆ...

ராஜப் : இப்போதாவது தெரிந்துகொள்...... நீ வாழ வேண்டிய அவசியத்தை.
