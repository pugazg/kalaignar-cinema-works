வசந்த விழாக் கொண்டாட்டம். பாட்டுகள்...
மனோகரனும் விஜயாவும் பாடுகிறார்கள்

விஜயா : இந்த அன்பு மாறவே மாறாதே...

மனோகரன் : இது என்ன கேள்வி விஜயா!

விஜயா : இல்லை... நீங்களும் மாமாவைப் போல்...ஒரு வசந்த சேனையின் மயக்கத்தில் விழுந்து விட்டால்

மனோ : வசந்த சேனா. அவள் பெயரையே என்னிடம் உச்சரிக்காதே!.........என் தாய் இருக்கவேண்டிய இடத்திலே அந்த நாய்.........தணலில் விழுந்த புழுவாக அவளைத் தவிக்கவிட்டு—என் தாயை கொலு மண்டபத்தில் அமர்த்தா விட்டால்...நான் மனோகரனல்ல.

விஜயா திடுக்கிட்டு எழுதல்...

விஜயா : ஆ!...

மனோ : என்ன?

வசந்தன் ஆசனத்தின் கீழிருந்து எழுந்து

வசந்தன் : காலை மிதிச்சுட்டியே அண்ணி!

மனோ : ஏ, நீ இங்கேயா ஒளிந்து கொண்டிருந்தாய்,

வசந் : உம்...பொம்பளைங்க எல்லாம் தண்ணியாலையும், பூவாலையும், தண்ணிப் பூவாலையும், பூத்தண்ணியாலையும், பூத்தண்ணியாலையும் தண்ணிப் பூவாலையும் அடிச்சா நீங்களுந்தான் ஒளியுவீங்க!

மனோ : (சிரிக்கிறான்...)தைரியசாலி...

விஜயாவும் சிரிக்கிறாள்......

வசந் : சிரிங்க...சிரிங்க...

அரசனுடன் வசந்தசேனை வந்து கொண்டே......

வசந்தி : வசந்தா!... வசந்தா!...

வசந்தன் : நான் இங்கே இருக்கேம்மா...ஏம்மா...

[அங்கே வந்து]

வசந்தன் : அம்மா!...அண்ணனும் அண்ணியும் என்னைப் பார்த்து சிரிக்கிறாங்க!...

<!-- source: pdf=42 printed=41 status=verified -->

வசந்தி : பாண்டியன் மகளை பாணிக்கிரகணம் செய்தது பற்றித்தான் ஊர் உன் அண்ணனைப் பார்த்து சிரிக்கிறது. தகப்பனைக் கொன்றவனுக்கு தாரமாய் வாய்த்ததைப் பற்றித்தான் உலகமே உன் அண்ணியைப் பார்த்து சிரிக்கிறது...

[பல்லைக் கடித்து]......

சிரிக்கிறார்களாம் சிரிப்பு...... எல்லாம் சிரித்துவிடுகிறேன்... வாடா நீ!...

வசந்தன் : அதெல்லாம் உன்னால் முடியாதம்மா!...உன்னை புழுமாதிரி தவிக்கவிடப் போவது அண்ணன் - ஜாக்கிரதை! இப்பத்தான் அண்ணிகிட்ட சொன்னது. என் அண்ணி!

[கேலியாக]

வசந்தி : உம்...வீராதி வீரர்களாலும் முடியாத காரியம் இந்த வேசி மகனால்தான் முடியப்போகிறது...

மனோகரன் : ஆ! என்ன சொன்னாய்?

[கட்டாரியை உருவுகிறான்]

நஞ்சு கக்கிய அந்த நாவைத் துண்டாடுகிறேன் பார்!...

[அதைத் தடுத்துப் பிடித்து]

அரசன் : மனோகரா! விடு

மனோகரன் : முடியாது நீர் உம் மனைவியின் மானத்தைக் காப்பாற்றாவிட்டாலும் நான் என் தாயாரின் மானத்தைக் காப்பாற்றியே தீருவேன்.

அரசன் : சொல்வதைக் கேள்...

மனோகரன் : முடியாது......உமக்கு வல்லமையிருந்தால் அவளைக் காப்பாற்றும்...

சத்யசீலர் : மனோகரா!...

விஜயா : அத்தான்! அத்தைக்குச் சொன்ன வாக்குறுதி

மனோகரன் : சீ......

[விஜயாவை அடித்துவிடுகிறான்]

மனோகரன் : அம்மா!...

[குழப்பத்துடன் போய்விடுகிறான்.]

அரசன் : வசந்தி!...நீ வரம்பு மீறிவிட்டாய்.

வ. சே. : ஸ்வாமி...

அரசன் : சீ...பேசாதே!
