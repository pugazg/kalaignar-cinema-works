(மனோகரன் தூணில் கட்டப்பட்டிருக்கிறான்)

வசந்தசேனை : மனோகரா! உன் உடலைத்தான் எல்லாரால் கட்டிப் போட முடிந்தது, உயிரைக் கட்ட முடியவில்லை. அது வெகு சீக்கிரத்தில் விடுதலை பெற்று வேறு உலகத்திற்குப் போய்விடும்!

மனோ : அம்மா! (உக்ரசேனன் அடிக்கிறான்)

மனோ : அம்மா!

உக்ரசேனன் : ஹூம் ஐயோ பாவம் இந்த மழலைக் குழந்தை மாதாவை அழைக்கிறது.

மனோ : அம்மா!

உக்ர : பரிதாபத்துக்குரியவனே! வாய் வலிக்க தாயை ஏன் அழைக்கிறாய்? கொஞ்சம் காத்திரு! உன் பாட்டி இருக்கும் பரலோகத்திற்கே உன்னை அனுப்பி வைக்கிறேன்.

வசந்தி : வேண்டாம். முதலில் குழந்தை! பிறகு மனோகரன்! அவன் கண்ணுக்கு நேராகவே அவன் கண்மணியைக் கொல்லவேண்டும். ஆயா! போ! குழந்தையைக் கொண்டுவா;

(வசந்தன் வருகிறான்)

வசந் : அண்ணா என்ன இது? உன்னை யார் கட்டிப் போட்டது?

வசந்தி : வசந்தா...

உக்ர : வா இங்கே

வச : முடியாது... எல்லாம் உன்னுடைய வேலைதானே! அம்மா... அண்ணனை அவிழ்த்து விடு! உம்

வசந்தி : வசந்தா... சும்மா இரு. உனக்கொன்றும் தெரியாது

வச : எனக்கெல்லாம் தெரியும். என் பிரியமுள்ள அப்பா, பெரியம்மா, அண்ணி எல்லோரையும் சிறையிலே போட்டே, அண்ணனையும் கட்டிப் போட்டு அடிக்க ஆரம்பிச்சுட்டே, என்னால் இதை அனுமதிக்க முடியாது.

வச : அண்ணா...

வசந்தி : வசந்தா...

வச : அண்ணா!......

வசந்தி : வசந்தா வா இப்படி

வச : அண்ணா அந்த சங்கிலியெல்லாம் அறுத்தெறி...... விடம்மா என்னை!

(ஒரு அறைக்குள் இழுத்து வருகிறாள்).

விடு என்னை... விடு என்னை.

வசந்தி : சும்மாயிரு எல்லாம் உன் நன்மைக்காகத்தான் செய்கிறேன்.

வச : ஆ! அண்ணனைக் கட்டிப் போட்டு கொல்றது தம்பியின் நன்மைக்காகவா!

வசந்தி : கண்ணே நீ ராஜாவாக வேண்டாமா!

வச : ராஜாவா? வேண்டாம்! வேண்டாம். அப்புறம் உன்கிட்டம் ஒரு ராணி வந்து சிறையிலே போடுவா! செத்தாலும் சாகிறேன். அந்த சிம்மாசனம் வேண்டாம்மா?

வசந்தி : எல்லாம் என் தலைவிதி! என் வயிற்றிலே வந்து நீ பிறந்தாயே!

வச : அதுக்காகத்தான் நானும் கவலைப்படுறேன்.

வசந்தி : வாயை மூடு

வச : முடியாது.

வசந்தி : முடியாதா?

வச : அம்மா! அம்மா! (கதவை சாத்திப்போகிறாள்)
