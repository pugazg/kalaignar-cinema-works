## திரைக்கதை வசனம்

★

(குகை உட்புறம் அரூபம் ஒரு சிலையை
செதுக்கிக்கொண்டிருக்கிறது அதன்
எதிரே புன்னகையுடன்.)

பெரியவர் : வெற்றி...வேதனையைப் பொருட்படுத்தாதவனுக்குக் கிடைத்த வெகுமானம்!... அநேக வருஷங்களாக பட்ட பாட்டிற்கு சரியான அறுவடை! இனி நினைத்ததை யெல்லாம் செய்து முடிப்பேன்...கேசரி வர்மா! கவலைகள் படிந்த உன் கண்களிலே களிப்பு பொங்கட்டும். துயர மேகங்கள் உன்னை விட்டுத் தூர ஓடட்டும். தொல்லைகள், இனி நமக்குத் தூசுகள்...... ஹா... ஹா... ஹா... வெற்றி; வெற்றி;

கேசரி வர்மன் குரல்மட்டும் கேட்கிறது.
சிற்றுளியும் சுத்தியும் தங்கள் வேலையை நடத்திக்கொண்டே யிருக்கின்றன.

கேசரி வர்மன் : குருதேவா! உண்மைதானா? நான் தெரியவில்லையா உங்கள் கண்களுக்கு!......

பெரி : ஆமாம் கேசரி வர்மா! அரூபமாகிவிட்டாய். கண்டு பிடித்த மருந்து வேலை செய்யத் துவங்கிவிட்டது. கிடைக்காதது கிடைத்துவிட்டது. என் ஆராய்ச்சிக்கு அமோக வெற்றி. எல்லோரையும் நீ பார்க்கலாம். ஆனால் உன்னை யாரும் பார்க்க முடியாது.

கேசரி : குருதேவா!...பதின்மூன்று வருடங்கள்...பதறிக் கிடந்தேன் அந்தப் பாவியைப் பழிவாங்க வேண்டுமென்று! பாதை வகுத்துக் கொடுத்து

விட்டபோது! ......சுவாமி! அரூபம் அதிக நாள் இருக்காதா?......

பெரி : இருக்காது - ஆனால் இன்னும் முயன்று பார்க்கலாம். நான் தேடும் மூலிகைகள் கிடைத்துவிட்டால் அரூபமாக மட்டுமல்ல, அழியாமலே கூட இருக்கலாம். ஆனால் கேசரிவர்மா! நல்லவர் வாழ இதைப் பயன்படுத்து!

கேசரி : நல்லவர் வாழப் பயன்படுத்துவேன்! அதே சமயத்தில் இந்த நாசகாரியின் நரி வேலைகளை அம்பலமாக்குவேன். பாவி! பழிகாரி................... கணவனுக்கு விஷங் கொடுத்த பத்திரகாளி! உன் விஷத்தால் செத்துவிடவில்லையடி. கேசரி வர்மன்! இருக்கிறான் உயிரோடு! சாகவில்லை - சாகமாட்டான், உன் சதியை வெளிப்படுத்தாமல்! வஞ்சகி!.....வாய் ஜாலக்காரி!

பெரிய : ஹ ஹ ஹ............

கேசரி : குருஜி.

பெரி : சிலையப்பா அது!

கேசரி : சிலைதான்! ஏன் செதுக்குகிறேன் இவளை! சித்திரவதை செய்வதற்கு ஒத்திகை பார்க்க; வசந்த சேனை! உன் விழியில் வேல் சொருகுவேன் - கூந்தலுக்கு தீ மூட்டுவேன் - கொவ்வை உதடுகள்!... அவைகளில் கூரிய ஊசிகளைக் குத்துவேன்..... கண்ணாடிக் கன்னம்! ஹா ஹா ஹா... கட்டாரியால் கிழிப்பேன்... காண்பவர் வெறி கொள்ளும் மேனி...கண்டம் கண்டமாக வெட்டி எறிவேன்! ஆரம்பமாகிவிட்டதடி, அரூபத்தின் அற்புத வேலைகள்!... மாயக்காரி, தொடங்கிவிட்டதடி உன் மாஜி கணவனின் பழிவாங்கும் படலம். நடமாடும் பாம்பே!... நாசத்தின் நர்த்தனமே! நயவஞ்சகப் பிசாசே... அரிக்கும் சிலந்தியே.........

வசந்த சேனையின் சிரிப்புடன் அரண்மனையில் காட்சி ஆரம்பமாகிறது.

வசந்தசேனை : பைத்தியக்காரி! இப்போது நினைத்தாலும் நான் பட்டமகிஷி ஆக முடியுமடி!......

தோழி : அதுதாம்மா எனக்கும் ஆசை. ஆனால் மகாராணியும், இளவரசரும் உயிரோடு இருக்கும்போது ...

வச : மகாராணி-இளவரசர்...இரண்டும் உயிர்ப்பிணங்கள் நான் சிரித்தால் போதும், சிம்மாசனமே கிடைக்கும். மயக்குகின்ற ஒரு பார்வை - இந்த மண்டலமே என் காலடியில்! மகாராஜாவின் பிரேமை ராணியடி நான்! நினைத்தால் போதும் - வசந்த சேனை ராணி! அவள் மகன் வசந்தன் இளவரசன்!

மாளிகையின் ஒரு பகுதியில்

வசந்தன் : ஆமாமாம் சந்தேகமில்லே விகடா! ராஜா மகன் இளவரசன்! இதிலே எனக்கு சந்தேகமில்லே...

விகடன் : வசந்தா! இதிலேமட்டுமா நமக்கு சந்தேகமில்லே... எந்த நாளிலும் எதிலும் நமக்கு எள்ளளவிலும் உள்ளபடிக்கு ஒரு சந்தேகமில்லே.

அரண்மனையின் மற்றொரு புறத்தில்

பத்மாவதி : (அரசர் படத்துக்கு முன்பு)
சுவாமி! நாமிருவரும் இனிமேல் ஒன்று சேரும் நாளே வராதா...? என் வாழ்க்கையிலே நான் யாருக்கும் எந்த தீங்கும் செய்தது கிடையாதே! என் வாழ்க்கையைக் கெடுத்த வசந்த சேனையைக்கூட மன்னித்து இருக்கிறேன்.... அவளிடம் வாஞ்சை மிகுந்து உங்களுக்கு வருத்தம் வரக்கூடாது என்பதற்காக!... அப்படியே நான் யாருக்காவது தீமை செய்திருந்தாலும் அதற்கு பல ஆண்டு காலம் தங்களைப் பிரிந்து வாடுகிறேனே! இந்த தண்டனை போதாதா? சுவாமி! கண்மணி மனோகரனின் பிறந்த நாளும் வருகிறது. எழில் பூத்த நம் செல்வத்தை இருவரும் உச்சி மோந்து வாழ்த்து கூறுவோமே - அந்த இன்ப நாள் இனிமேல் வரவே முடியாதா சுவாமி!

பெரியவர் : எங்கே கேசரி வர்மா அவசரமாகப் புறப்பட்டு இருப்பாய்?

கேசரி வர்மன் : நாடகத்திற்கு - அதோ அவர்களைத்தான் ஏற்பாடு செய்திருக்கிறேன்.

பெரி : மறந்துவிட்டேன். இன்று மனோகரன் பிறந்த விழாவா? உம் ... நாடகத்திற்கு என்ன பெயர் வைத்திருக்கிறாய்?

கேசரி : போர்வாள்.

பெரி : சபாஷ் ... தடையொன்றும் கிடையாதே நடத்துவதற்கு?...

கேச : கிடையாது. காரணம், கதை அவர்களுக்குப் புரியாது...

பெரி : வசந்த சேனைக்கு உன் நாடகத்துப் புனைப்பெயர் என்ன?

பெரி : கட்டாயம் புரிந்துகொள்வார்கள் கதையை.

அப்போது சிப்பாய் உடையில் யாருக்கும் தெரியாதபடி உருவிய வாளோடு நுழைந்த விஜயா தன்னை அறியாமல் ‘ஓ’ வென அலறுகிறாள்.

மனோகரன் விழித்தெழுந்து விஜயாவின் கையைப்பிடித்துக்கொண்டு

மனோ : யாரடா நீ

விஜயா : நீர் உண்டாக்கிய சுடுகாட்டிலே மறு உயிர் பெற்ற பேயுமல்ல, பிணமுமல்ல! உனது பார்வையில்

தட்டுப்படாமல்போன பகைவர்களில் ஒருவன்—பாண்டிய நாட்டு வீரன்!

மனோ : பாண்டிய நாட்டு வீரன்! உம்...பாதி ராத்திரியிலே பதுங்கிப் பாயும் பட்டாளப் பயிற்சிக்கு முத்து விஜயன் ஆட்சியிலே முதல் இடம் போலும், முதுகெலும்பில்லாதவனே. கையிலே வாளும், நெஞ்சிலே கோழைத்தனமும் கொண்டவர்களில் ஒருவன் மிச்சமா? ஓடிப்போ...உயிரைக் காப்பாற்றிக்கொள்...

ராஜப்பிரியன் : மனோகரா!...இவனை விடக்கூடாது...

மனோ : போகட்டும் பாவம்...மன்னித்துவிட்டேன்

விஜ : மன்னிப்பு கேட்கும் மரபல்ல...

மனோ : மறைந்திருந்து தாக்கும் மரபு...மாவீரன்!

ராஜ : தூங்குபவன் தலையைத் துண்டாடுபவர்களும் வீரர்கள்தான், பாண்டியநாட்டுப் பள்ளிக்கூடத்திலே! போடா போக்கற்ற கோழையே!

விஜ : கோழை...நானா கோழை! இதோ பார்...இப்பொழுதே நேராகவே பழிதீர்த்துக்கொள்கிறேன்....

[வாளை உருவுகிறாள். மனோகரன் அவளைத் தடுக்க அப்போது அவள் தலைப்பாகை நழுவுகிறது.]

மனோ : ஆ! பெண்!

விஜ : உன் பகைவரின் பெண்... பழிவாங்க வந்தவள்...

ராஜ : இளவரசி!

மனோ : அற்புதமான காட்சி, வளையல் ஏந்தும் கைகளிலே வாள்!

விஜ : பேசாதீர்!... நீர் வீரனெனில் என்னை ஜெயித்த பிறகு பேசும்!

மனோ : வேல்விழி மாதர்களிடம் வீரர்கள் ஜெயித்தார்கள் என்பதற்கு சரித்திரமே கிடையாது, இளவரசி!

விஜ : கேலி தேவையில்ல...எடும் வாளை,

மனோ : என் வாள் களத்திலேதான் விளையாடும்... கனிகளைக் காயப்படுத்தாது!

விஜ : துணிவிருந்தால் - வீரர் லக்ஷணத்தைப்பற்றி பேசியதெல்லாம் வாய்வீச்சாக இல்லாமல் இருந்தால் வாளை வீசும்... நல்ல தீர்ப்பு கிடைக்கட்டும்....

மனோ : நல்ல தீர்ப்பு...வாள்முனை வழங்காது இனிமேல் வழக்கு மன்றத்திலே தான் பெறவேண்டும்! பாண்டியன் பெற்ற பைங்கொடியே நீ இப்போது கைதி - பாதுகாப்புக் கைதி! ராஜப்பிரியா! அழைத்துச் செல்!

ராஜப் : அதோ கோட்டை வாசலிலே எங்கள் கொடி! ராஜகுமாரி மனோகரனின் அடிமை என்பதை அறிவிக்கும் கொடி!

விஜயா : பேசாதே! அரசிளங் குமரியாக வாழ்ந்தேன் - அடிமையாக வாழமாட்டேன். வானம்பாடியாகத் திரிந்தேன் - வல்லூறுகளின் கோரப் பிடியிலே சிக்க மாட்டேன். சுதந்திரத் தென்றலிலே மிதந்தேன் - அடிமைச் சூறாவளியிலே அகப்பட்டுக் கொள்ளமாட்டேன் - மாற்றானின் காலடியைவிட மரணத்தின் மடி எவ்வளவோ மேல்.

விஜயா அந்தப்புரம் “வாழ்வதே மாது நான்” பாட்டு.

விஜயா விஷம் அருந்த முயற்சிக்கிறாள்.

(உள்ளேவந்து) மனோகரன் : விஜயா! தற்கொலை கோழைத்தனம்!

விஜயா : இருட்டு வேளையில் பெண்களின் அந்தப்புரத்தில் நுழைவது அதைவிட கோழைத்தனம்...

மனோகரன் : பரவாயில்ல. மரணப் புயலிலிருந்து ஒரு மலர்க் கொடியைக் காப்பாற்றி யிருக்கிறேன்.

விஜயா : இந்த அடிமையின் சாவை யாரும் தடுக்க வேண்டாம்.

மனோகரன் : அடிமையார் அடிமை? அழகே உருவான ராஜகுமாரி நீ...
