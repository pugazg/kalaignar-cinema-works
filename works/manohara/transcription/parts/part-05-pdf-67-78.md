[குகையருகிலுள்ள கல் தூணில் கட்டப்பட்டிருக்கும் உண்மை அக்ஷயன் கஷ்டப்பட்டு கயிறுகளை அறுக்கிறான்.]

அரண்மனை

வசந்தசேனை : நாளை ஆகவேண்டிய காரியத்தை ஆலோசிப்போம்.

உக்ரசேனன் : இனியும் என்ன ஆகவேண்டியது?

சேனா : நாளை வசந்தனின் பட்டாபிஷேகம்.

உக் : நிச்சயமாக ஆனால் அதற்குள் நாடு நம் வசமானதை அறிவிக்க வேண்டும்.

சேனா : அறிவிப்பதால் ஏதாவது ஆபத்து?

உக் : ஆபத்து!... யாரால்? என்னை எதிர்க்கக் கூடியவர்கள் இந்த உலகத்தில் இருக்கிறார்களா?

சேனா : உற்சாக வெள்ளத்தில் உயிரோடு இருக்கும் மனோகரனை! மறந்துவிடக் கூடாது.

* *

சிறைச்சாலை. முத்திரை மோதிரத்தைக் காட்டி உள்ளே நுழைகிறான் மனோகரன்.

மனோ : அம்மா

பத்மாவதி : நீ யார்!

மனோ : மனோகரன்... என்னை அனுப்பினான்!

பத் : மனோகரன்... என் கண்மணி சுகமாக இருக்கிறானா?

விஜயா : அத்தே! அவர் எங்கிருக்கிறாராம்?

மனோ : சதா உங்கள் இருதயத்திலே இருக்கும் அவர் வேறு எங்கு இருப்பார்.

பத் : யாரப்பா நீ?

மனோ : அதைப் பிறகு சொல்லுகிறேன். இப்போது நீங்கள் இருவரும் இதை விட்டு தப்பிவிடவேண்டும்.

பத் : என்ன?

மனோ : ஆமாம்) மனோகரனின் ரகசிய ஏற்பாடு. இதோ முத்திரை மோதிரம் பயமின்றி யாருடைய தடையுமின்றி வெளியேறலாம். புறப்படுங்கள்.

பத் : தந்திரமாக தப்பிவிடுவது—கூடாது, முடியாது. மகாராஜாவின் உத்திரவை மீற முடியாது. மனோகரனிடம் சொல்லிவிடு.

விஜ : அத்தே!

: தம்பி மனோகரனிடம் சொல்—எனக்கு ஒரு செல்வப் பேரன் பிறந்திருக்கிறான், சிறைச்சாலையில் என்று!

<!-- source: pdf=78 printed=77 status=draft -->

மனோ : இந்தப் பேரனுக்கு வரும் பேராபத்தை நீக்கத்தான் நீங்கள் வெளியேற வேண்டுமென்றேன்.

பத் : அரசன் கட்டளையை... அரசியே மீறுவதா? முறையல்ல.

மனோ : அப்படியானால்... ராஜகுமாரி! அந்த குழந்தையையாவது கொடுங்கள் நான் கொண்டுபோய்விடுகிறேன்.

விஜ : ஆ! குழந்தையா?

மனோ : குழந்தையின் உயிரைக் காப்பாற்ற வேண்டுமானால்......?

விஜ : அத்தே இவன் நம்பாதீர்கள்...... குழந்தையைக் கொல்லுவதற்கு ஏதோ சூழ்ச்சி நடக்கிறது.

மனோ : இல்லை! இல்லை!......

விஜ : முடியாது... முடியாது... நீ போய்விடு.

* * *

அரண்மனை.

சிப்பாய் : மகாராஜா! அக்ஷயன் வந்திருக்கிறார். பார்க்க வேண்டுமாம்.

வ. சே : வந்துவிட்டானா? இங்கே வரச்சொல்.

: வெற்றிச் செய்தியோடு வந்திருப்பான். விஜயாவின் குழந்தையைக் கொன்று விட்டுவந்திருப்பான். அவனுக்காக இந்தப் பரிசு

: உங்கள் தளபதி மிகவும் தந்திரசாலி.

உக்ரசேனன் : அதில் சந்தேகமென்ன? ஓ... வா... அக்ஷயா வா...

: என்ன அக்ஷயா? [உண்மை அக்ஷயன் வருகிறான்]

சேனா : யார் இவனா அக்ஷயன்?

உக் : ஆமாம்.

சேனா : ஆ! இல்லை.

அக்ஷயன் : நான் தான் உண்மையான அக்ஷயன், உங்களை இது வரை ஏமாற்றியது போலி அக்ஷயன் அம்மணி!

: மகாராஜா! என்னைக் கட்டிப் போட்டார்கள், இப்போதுதான் தப்பி வந்தேன்.

உக் : கட்டிப் போட்டார்களா? யார்?

அட் : மனோகரன்!

சேனா : ஆ! மனோகரன்! அப்படியானால் இங்கு இருக்கிற அக்ஷயன்?
