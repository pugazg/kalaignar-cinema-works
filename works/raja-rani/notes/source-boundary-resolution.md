## Scene-separator resolution

The source uses recurring star ornamentation to mark dramatic separation, but not one uniform typographic form.

Verified forms include:

- a centered row of multiple stars (for example PDF 10);
- rule–star–rule dividers (`—★—`, for example PDF 25);
- star-flanked location/section headings (`★ தோட்டம் ★`, PDF 79).

OCR is not reliable for these ornaments and often turns them into dashes, letters, symbols, or garbage. The rendered scan controls separator identification.

## Scene mapping rule

Scene records will only be created from source-supported separators/headings and dramatic transitions. PDF page changes alone will not define scenes. Embedded dramas remain in the parent film's canonical source order, and the exact printed ornament must be preserved in the canonical Tamil layer.
