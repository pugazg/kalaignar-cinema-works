# Raja Rani — verified Tamil song derivatives

This directory contains standalone derivatives for the **11 numbered `பாட்டு` blocks** printed in the Raja Rani booklet's verified song section, PDF 4–9 (first part of PDF 9).

## Authority

The controlling text is `works/raja-rani/pages/004.md` through `pages/009.md`, which were visually verified against the supplied scan. These files preserve the Raja Rani booklet's own wording, spelling, punctuation, speaker labels, lineation and page boundaries.

A later Kalaignar film-song anthology is used only as an authorship/item-identity cross-witness for five songs. Its textual variants are **not** imported here.
