# Parasakthi scene derivatives

This directory will contain one Markdown file per **observed printed scene heading** after the corresponding canonical Tamil text is verified.

Scene files are derivatives, not the controlling transcription.

## Naming

Use the printed scene number, for example:

- `scene-001.md` for `காட்சி-1`
- `scene-022.md` for `காட்சி-22`
- `scene-043.md` for `காட்சி-43`

Do not create synthetic files for scene numbers that are not actually present in the source unless a later research note explicitly justifies a reconstruction.

## Source-order anomaly

The booklet's printed order is authoritative for source provenance. `காட்சி-43` occurs after `காட்சி-46` and `காட்சி-47`; a numeric index may sort scenes separately, but it must not conceal the source order recorded in `mapping.md`.
