# Parasakthi song / verse index

This directory is for song-specific derivatives and attribution records.

The source booklet contains verse/lyric-formatted material, but its credits page visibly lists multiple song/lyric contributors. Therefore **presence in this booklet is not sufficient evidence that a particular lyric was written by Kalaignar**.

## Required fields for a future song record

Each song file should record:

- source PDF page(s)
- printed page(s)
- scene heading/context
- opening line or source title, if printed
- lyricist as printed, if explicitly given
- authorship status: `verified`, `probable`, or `unresolved`
- attribution source/reference
- canonical Tamil transcription status

The canonical source-order text remains in `../transcription/full-text.md`; this directory must not become an alternative transcription source.
